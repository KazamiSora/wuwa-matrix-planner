终焉矩阵血线排布 V0.2.2

运行
1. 将整个压缩包解压到任意可读目录。
2. 双击“终焉矩阵血线排布.exe”，自动打开独立应用窗口。
3. 运行时会在系统托盘显示图标。关闭窗口后可双击托盘图标重新打开；右键托盘图标选择“退出软件”会停止本地服务。

无需另装 Node.js 或 Python，无需联网下载头像。Windows 10/11 x64 可用；独立窗口优先使用本机 Edge，其次 Chrome，均没有时使用默认浏览器。

保存与迁移
排布自动保存在本机应用窗口的浏览器数据中。建议同时导出 JSON 备份。
更新前请切换到每套需要保留的方案，分别导出 JSON 备份。
右键旧版的系统托盘图标，选择“退出软件”，再把 V0.2.2 完整解压到新目录后启动，不要只替换 exe。
保存记录与浏览器数据及访问端口有关；新版如果没有显示旧排布，逐个导入备份即可。从之前 Demo 迁移也可使用 JSON 导入。
每套排布分别保存队伍、分数、矩阵期数、体力规则和目标标记，可以切换、复制、重命名或复制 JSON 配置。导入 JSON 会新增方案，保留已有方案。
不需要的方案可以永久删除，也可以先“导出后删除”。请确认备份已保存，再确认删除；删除后无法在软件内撤回。
Boss、抗性、特殊性质、血量、分数、体力和矩阵增益保存在 config/seasons 下对应赛季的 JSON 文件。

主要操作
- 选 3 人组队，按首字自动命名。分数可以先留空，队伍会按 5000 分在轴上显示预览；补上实际分数后重新计算长度。
- 快捷组队窗口已加大，电脑上随屏幕宽度显示 10、12 或 14 列头像，手机上显示 4 列。角色剩余体力放在头像左上角，多体力标记放在右下角。
- 快捷组队左侧显示已有队伍及本次组队进度，列出角色头像和姓名。每 3 人一队，加入后直接在轴上按 5000 分显示预览。撤回、恢复、重置只影响本次选人草稿。
- “我的队伍”右侧点“一览表”，可以按出场顺序集中查看当前排布的队名、三人阵容及分数，也能看到待填分数的队伍。一览表用于查看，编辑仍在队伍设置中进行。
- 色条首尾衔接，拖动调整顺序，双击打开编辑。待填队伍以及受其影响的后续队伍，起止位置会标为“预览”。
- 队伍设置旁的“撤回”“恢复”支持最近两次队伍删除操作，各排布方案独立记录，保留其他队伍后续修改；这套记录在当前页面会话中保留，刷新后清空，与快捷组队草稿分开。删除整个排布方案仍为永久删除。
- 悬停查看阵容、起止百分比和剩余分数；输入目标总分可定位并留下标记。
- 新建排布时可选终焉矩阵 S2-3 或 S2-4，体力规则可单独选择；切换体力规则有冲突时会列出涉及的角色和队伍。
- “显示至”可选 R1—R15；“全部血线”只适配当前所选轮次范围。
- 点击 Boss 血线可查看抗性图标、特殊性质、总血量和总分数，填写剩余血量百分比后显示已获取分数和剩余分数。矩阵奇藏的 1000 分奖励在剩余 0% 时计入。
- 页面下方的回路增益、Boss 特殊性质和其余角色强化默认收起；对应赛季体力 +1 的角色常驻显示。Boss 特殊性质位于角色强化上方，列出两期共 8 只 Boss，可搜索名称、简称或性质关键词。

数据说明
S2-3 的 R1—R3 总血量取自原表，R4 起按原表规律推算并标注“推算”。
S2-4 的血量和分数暂按 S2-3 相同轮次、相同出场位次沿用，均标注“暂定”，尚未实测。
抗性按基础全属性 20%、对应高抗属性 40% 显示，特殊性质说明供配队时参考；增益、抗性和特殊性质不会自动改变手填分数。

退出或故障
默认监听本机 4174 端口，必要时尝试后续端口，不对局域网开放服务。
程序文件需要保持在同一目录，不要单独移动 exe 或 runtime 文件夹。
如果无法启动，检查是否完整解压，以及本机安全软件是否阻止运行。
